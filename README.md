# Queen Rescue RPG

An Android role-playing game developed using Android Studio.

## Features
- RPG-style gameplay mechanics
- Android UI interaction
- Structured application logic using object-oriented programming

## Technologies Used
- Java / Kotlin
- Android Studio
- Gradle

## Purpose
This project was created to practice mobile game development and application structure.
