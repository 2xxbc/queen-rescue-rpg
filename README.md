# Queen Rescue Game (Android RPG)

An Android RPG game built in Android Studio.

## How to Run
1. Open the project in Android Studio
2. Let Gradle sync
3. Run on an emulator or Android device

## What This Shows
- Mobile app structure (Android)
- Game logic and UI interaction
- Object-oriented programming

## Tech Used
- Android Studio
- Gradle
- Java/Kotlin

## Features
- RPG-style gameplay mechanics
- Android UI interaction
- Structured application logic using object-oriented programming

## Purpose
This project was created to practice mobile game development and application structure.
